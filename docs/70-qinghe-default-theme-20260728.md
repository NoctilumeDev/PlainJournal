# 青荷默认主题优化

> 完成日期：2026-07-28  
> 范围：顾客商城视觉令牌、主题默认值、切换持久化与真实浏览器验收  
> 边界：不进入 M9，不改变后端业务、权限或交易契约

## 1. 设计结论

顾客商城默认主题由“素白”调整为“青荷”，“素白”继续作为全局索引内的备用主题。
两者仍是同一套设计语言，不引入荷花图片、纹样、水波、古典字体、印章、书法或国风
装饰。

青荷的分工是：

```text
主骨：荷青
呼吸：淡青与烟水灰
层次：远天蓝
中和：清水白
收束：深荷青与青墨黑
```

页面、内容面、商品图片区、文字、边界、主行动和辅助蓝色分别使用独立令牌，不是只
切换一个强调色。

## 2. 当前令牌

| 层级 | 青荷 |
| --- | --- |
| 页面背景 | `#F2F7F6` |
| 内容面 | `#FAFCFB` |
| 柔和区块 / 商品图片区 | `#E7F0EE` |
| 主文字 | `#1E2725` |
| 次级文字 | `#64736F` |
| 设计参考次级灰青 | `#6E7C79` |
| 边界 / 强边界 | `#D9E5E2` / `#C5D3D6` |
| 荷青 / 深荷青 / 浅荷雾 | `#6F8F8B` / `#4F6A67` / `#A8C6C1` |
| 远天蓝 / 山烟蓝 / 深远蓝灰 | `#B8CBD6` / `#D8E5EC` / `#7F97A3` |

`#6E7C79` 在当前浅背景上用于小号正文时不足 WCAG 4.5:1，因此实际次级文字微调为
`#64736F`，原色只保留为空气层令牌。`#6F8F8B` 配浅色普通按钮文字也不足 4.5:1，
所以品牌与选中线仍使用荷青，主要按钮使用 `#4F6A67` 配 `#FAFCFB`；该组合对比度
约 5.68:1。

价格保持主文字或深荷青；危险、警告、退款和成功等语义色未随主题改变。

## 4. 视觉边界

- 青绿承担品牌中心，蓝色只负责搜索画布、空状态和商品媒体的空气层。
- 不把蓝绿五五开，不使用鲜艳翡翠绿。
- 不使用参考图本身作为背景。
- 不增加长期占位的主题工具栏；切换仍位于全局索引。
- 动画只做约 260 ms 的背景、文字和边界过渡，并尊重减少动态效果。
- 本批不重构导航、商品内容或交易页面结构；这些应按产品计划另做独立切片。
