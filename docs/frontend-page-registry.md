## 维护规则

1. 新增、删除或改名路由时，必须同时更新注册表；
2. 动态路由必须提供可由演示数据稳定打开的 `samplePath`；
3. 页面家族只能使用现行计划定义的 A-F；
4. `factOwners` 记录最终事实所有者，不记录缓存、网关或前端 store；
5. 关键状态必须包含该页面真实存在的空、错、加载、权限或结果未知状态；
6. 页面视觉迁移前后都使用同一页面 ID、路径、数据与视口截图；
7. 第 34 页只能在产品用途、入口与真实路由三项同时确认后转为正式记录。

## 自动校验

在仓库根目录运行：

```powershell
node tools/check-frontend-page-registry.mjs
node tools/check-frontend-baseline.mjs
```

校验器会核对两端路由集合、组件文件、页面 ID、样例路径、页面家族、视口、33/34
口径，以及 66 张截图的尺寸、文件内容和 SHA-256。两项检查同时接入仓库 CI，防止文档、
截图与真实路由再次漂移。
